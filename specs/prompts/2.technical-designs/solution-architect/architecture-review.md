## Principal Architecture Review

### Objective

Perform an independent architecture review.

---

### Prompt

Act as an independent Principal Architect conducting a formal architecture review.

Review the Solution Architecture Document.

Do not rewrite the document.

Instead, perform a detailed engineering review.

Evaluate:

- Completeness
- Correctness
- Consistency
- Scalability
- Reliability
- Security
- Performance
- Maintainability
- Extensibility
- Cost implications
- Operational complexity
- Technical debt
- Diagram quality
- Missing scenarios
- Missing failure cases

For every issue provide:

- Severity
- Description
- Impact
- Recommendation

Also identify:

- Hidden assumptions
- Architectural smells
- Overengineering
- Underengineering
- Violations of best practices

Finish with an overall architecture readiness assessment.
